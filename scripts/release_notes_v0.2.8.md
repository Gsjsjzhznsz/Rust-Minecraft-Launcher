# Quartz v0.2.8 —— Svelte 5 前端重构（2026 Aurora 视觉）

## UI 全面重构：原生 TS + 手写 DOM → Svelte 5 组件化

- **框架**：Svelte 5（runes 响应式）+ Vite 6 + TypeScript，编译后零虚拟 DOM 运行时，前端总体积 **119KB（gzip 42KB）**，WebView 首屏更快
- **视觉方向（2026 大众审美调研结论）**：
  - **Aurora 极光背景**：深空底色 + 绿/青/蓝/紫四色漂移光晕（transform-only GPU 动画）
  - **Glassmorphism 2.0**：多层模糊玻璃卡片 + 渐变描边 + 顶部高光
  - **Bento 网格主页**：hero 启动卡 + 控制台 + 目录卡分栏布局
  - **动效主导**：页面转场、卡片分层入场、进度条流光、呼吸光晕启动按钮、LED 脉冲徽章
  - **性能红线**：不动 blur 半径、backdrop-filter 回退、prefers-reduced-motion 全降级
- **手机优先**：悬浮玻璃底导航（6 入口）+ 顶栏账户；宽屏自动切侧栏双列
- **功能 1:1 保留**：登录 / 版本下载 / Modloader / 实例 / 内容 / 账户（离线+微软+authlib）/ 设置全部 40+ 后端命令与 12 个事件通道

## 修复

- **版本下拉默认值丢失**：重构时发现并修复——清单加载后自动恢复上次选择，无法恢复时取第一个版本
- **滚动容器断裂**：`#app` 高度链修复，设置页长内容可完整滚出底导航遮挡区
- **移除幽灵副本** `src-tauri/ui/`（未入库的死副本，历史"改了没生效"的嫌疑根源），UI 真源唯一化为 `apps/shell-tauri/ui/`

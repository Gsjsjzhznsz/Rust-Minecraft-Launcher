# Quartz v0.2.3 — 触摸/按键修复

## 修复

### 触摸与虚拟按键全无响应（核心）
- **根因**：Rust 显示桥（quartz-bridge）的 GLFW 回调注册宏把游戏注册的回调指针写入模块级 static，而每帧事件泵（`pojav_pump_events`）读取的是 State 结构体字段——两处存储互不连通，全部回调槽恒为 0。
- **表现**：MC 注册的光标位置 / 鼠标按键 / 键盘 / 字符 / 滚轮回调一个都收不到，触摸移动可见（启动器自绘光标）但游戏内点击、WASD、热键全部无效。
- **修复**：宏改为与事件泵同源写 `State.cb_*`，五种输入事件链路全部打通。

### 虚拟按键错位（三处，实机截图确认）
1. **主菜单叠满游戏按键**：热键 1-9 列与滚轮 ▲▼ 列初始即以 VISIBLE 显示——此前只靠游戏 grab 回调切换，主菜单阶段从不回调。现在初始即为菜单模式：只留 顶部功能键 + 左上系统键 + 虚拟光标，移动/动作/热键全部隐藏（对标 FCL）。
2. **右缘热键列与右下动作键重叠**（跳跃/潜行/丢弃/副手/攻击 与 4/5/6/7/8 相互遮挡）：热键 1-9 + 滚轮 ▲▼ 合并为**底中央横排**，抬高避开 MC 自绘热栏与系统手势条。
3. **顶部按键被状态栏遮挡**（聊天/键盘/灵敏度）：容器按 WindowInsets 打 padding，状态栏/手势条/刘海自动避让。

## 升级说明
- 菜单模式：触摸 = 鼠标（按下即左键，长按 600ms = 右键，第二指上下滑 = 滚轮）。
- 游戏内（grab）：拖动 = 视角，轻点 = 左键，第二指 = 右键；方向键/动作键/热键横排此时出现。
- 左上「疾跑」开关、双击 W 疾跑、灵敏度面板、键盘按钮逻辑不变。

## 实例体系

实例 = 一份隔离的游戏目录。每个实例拥有独立的：

- `saves`（存档）、`mods`（模组）、`resourcepacks`（资源包）、`shaderpacks`（光影）
- 独立的 MC 版本、装载器、内存配置

同时**共享**同一份 `assets` / `libraries` 仓库 —— 装十个 1.20.4 实例也只下载一次公共资源。
实例清单（`instances.json`）为原子写入，损坏不会丢数据。

## 创建与选择

1. 「实例」页点「新建」，填名称、MC 版本、装载器、内存。
2. 选中实例后，主页启动即以实例隔离模式运行（日志会标注隔离目录）。
3. 也可以删除实例 —— 共享仓库不受影响，其他实例照常启动。

## 装载器安装

「实例」或「下载游戏」页可为版本安装 Fabric / Quilt 系装载器：

- 装载器版本列表在线获取，区分稳定版与 Beta。
- 安装完成后，新版本（如 `1.20.4-fabric-0.15.11`）直接出现在主页版本列表。
- Forge / NeoForge 的完整安装器编排按路线图 M2 落地。

## 整合包（.mrpack）导入

Quartz 内置 `.mrpack` 解析（Modrinth 格式）：

- 按 `env.client` 字段过滤客户端侧依赖。
- 导入后自动创建实例并下载模组与资源。
- Modrinth / CurseForge 双 API 浏览与一键安装在路线图 M2 提供。
